Bienvenue sur le dépôt de mon exercice interactif **Introduction to Git** réalisé via [GitHub Skills](https://github.skills.github.com/). Ce projet met en pratique l'utilisation du contrôle de version Git pour développer et gérer un jeu en utilisant la ligne de commande (CLI) et **Visual Studio Code**, sous la supervision de Mona (le bot GitHub Actions).
---

## 🎯 Contexte et Objectif du Projet

Cet exercice pratique fait partie du parcours d'apprentissage officiel de GitHub. À travers des instructions automatisées et un suivi en temps réel par les workflows GitHub Actions, ce dépôt valide ma capacité à manipuler l'historique d'un code source, à collaborer efficacement et à structurer un projet de développement de manière professionnelle.

---

## 🕹️ Le Projet (Jeu)

Le dépôt contient les fichiers de base d'un mini-jeu sur lequel j'ai appliqué les différentes opérations de versioning Git :
- Initialisation et suivi des modifications du jeu.
- Création de branches dédiées aux nouvelles fonctionnalités.
- Fusion des modifications et validation des étapes guidées par le bot d'évaluation.

---

## 🛠️ Compétences Techniques Démontrées 

Ce dépôt atteste de la maîtrise des fondamentaux indispensables en génie logiciel :
- **Collaboration & Dépôts Distants** : Synchronisation avec GitHub (`git push`, `git pull`, gestion des remotes).
- **Command Line (CLI) & VS Code** : Utilisation fluide du terminal et de l'éditeur de code pour exécuter les commandes Git.
- **Gestion des modifications (Staging & Commits)** : Suivi de l'état des fichiers (`git status`), préparation (`git add`) et enregistrement propre de l'historique (`git commit`).
- **Branching & Workflow de travail** : Création, bascule et fusion de branches (`git branch`, `git switch`, `git merge`) pour isoler et structurer le travail.
- **Validation CI/CD** : Interaction avec les actions automatisées GitHub Actions pour valider chaque étape de l'apprentissage en temps réel.
